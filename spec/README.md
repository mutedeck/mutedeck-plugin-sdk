# Spec copy

`openapi.yaml` here is a **copy**. The source of truth is the MuteDeck desktop
repository: `client/docs/plugin-api-v2/openapi.yaml`.

Do not edit this file by hand. Update the desktop spec, then run:

```sh
npm run sync-spec   # copies ../client/docs/plugin-api-v2/openapi.yaml
npm run generate    # regenerates packages/js/src/generated/schema.ts
```

The .NET message records (`packages/dotnet/src/MuteDeck.PluginClient/Messages.cs`)
are hand-written and must be updated alongside the spec; their tests check the
shapes against the spec's examples.
